SAS → PySpark converter

Paste SAS. The Prolog DCG and the Rust engine each fold it to node/4, print it back, and generate PySpark from the same rules. The receipts tell you whether the two agreed.

SAS in
PySpark out 
—
plain printer output (the proof version, same node/4)
—
node/4 — the parse, one fact per statement
—
SAS rebuilt from node/4 (same rules) — must equal the input
—
canonical spelling (one space per token)
—
rows the PySpark produced
—
