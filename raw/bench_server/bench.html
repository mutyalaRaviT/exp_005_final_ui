Keys

    
Single letters work in COMMAND mode, like Jupyter. ⏎ edits the focused cell, esc leaves it. ⌃⏎ and ⇧⏎ run in both modes.

    

      
⌃⏎ / eRun the focused cell, like Jupyter. Jupyter view: SAS block left (executable node/4) and its PySpark right, same Z3 inputs, tables and a DataMatch badge under both. IDE view: the # %% region under the cursor.

      
⇧⏎Run and move to the next cell.

      
jJupyter view: aligned SAS / PySpark cell pairs. Press j again to hide the text buffer; the viewer takes the width.

      
iIDE view (i again hides it): the whole PySpark file as one buffer, no cell chrome. Only # %% lines make cells; type one and the gutter shows the new cell at once.

      
⇧eRun every pair from the top to the focused one, in order.

      
bFiles: corpus, outputs, notebooks, and programs similar to this one.

      
cCells as a lineage tree: a block sits under the table it reads. Click one: everything before it stays solid and numbered, everything after it goes transparent. Esc clears.

      
gTable lineage graph. Click a table to highlight the cells that make or read it.

      
lOpen the bottom split on the terminal / log.

      
pConsole on the right: python mode runs the text in the kernel (or local python), terminal mode sends each line to the gated terminal. ⌃⏎ runs, ⇧⏎ runs and clears.

      
⌘⇧dSplit the right dock: Output / Terminal / Log / DataMatch under the viewer. The left stays text.

      
⌃⇧cClose that split.

      
↓Focus next cell.

      
↑Focus previous cell.

      
1Left column only (fold PySpark).

      
2Right column only (fold SAS).

      
0Both columns.

      
rSwitch engine: Rust ⇄ Prolog. Both must agree; the receipt bar shows it.

      
paste linkPaste a Jupyter URL in the top bar: the bench attaches to that server, one kernel per open file, and cells execute there. Several sessions run in parallel; click a chip to switch.

      
⌘⇧pCommand palette: every action here, fuzzy-searchable.

      
⌘pFile finder: jump to any file in the corpus or out/.

      
⌘kType in the file name at the top: files and folders match as you type; Enter opens, Esc puts the name back.

      
⌘jBottom strip: open, or collapsed to its one status line. ⌃⇧C closes it.

      
⇧gGraph alone: hides the text buffer. ⇧G, j or i brings the text back.

      
dragThe files dock and the divider between the two buffers drag to resize. The bottom strip is fixed.

      
dRun upstream first: any table this block reads that has not run yet runs before it, in lineage order. ⌃⏎ does this too; ⇧E stays positional.

      
[Focus a maker of what this block reads; press again to cycle. The shared table lights up in the graph.

      
]Focus a reader of this block's table; press again to cycle.

      
sBackward story of the focused table: every upstream table numbered source → here, in the graph and on the cells. Clicking a graph node does the same; double-click focuses its maker. Esc clears.

      
tTheme: system, dark, light. Remembered in this browser.

      
/Filter the files dock; Enter opens the first match.

      
?This card. Every row here is clickable and runs the action.
